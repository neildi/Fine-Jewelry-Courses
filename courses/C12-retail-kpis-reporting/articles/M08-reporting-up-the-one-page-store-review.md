# Reporting Up: The One-Page Store Review

## Why This Module Matters

Every KPI this course has built — conversion, ATV, UPT, sell-through, GMROI, retention — and every diagnostic skill Module 7 just covered means little if a store leader can't communicate results upward in a way that gets a district manager's attention, confidence, and support. This closing module covers the specific structure for turning a week or month of store performance into a one-page review that a busy leader can absorb in under two minutes, and covers the parallel skill this course's terminal outcomes require: translating a store-level target into a fair, specific target for each individual associate.

## The Three-Part Flow Every Good Report Follows

A specific, simple structure underlies effective upward reporting: context, then insight, then action. Context is what happened — the actual number, plainly stated. Insight is why it happened — the driver, identified using exactly the diagnostic discipline Module 7 built. Action is what happens next — a specific decision, not a vague intention. A report that stops at context ("sales were down 8 percent") forces the reader to ask the two follow-up questions themselves; a report that includes all three in a single, tight paragraph answers the questions before they're asked, which is exactly what separates a report a district manager trusts from one they have to interrogate.

## The Four Required Fields of a Genuinely Useful Summary

A well-documented executive-summary structure names four specific fields that belong in any leadership-facing performance summary: the current-period result (the primary outcome number, like net sales or gross margin dollars), the comparison (variance to plan and variance to the same period last year), the driver (naming the two or three specific measures that explain the movement — traffic, conversion, availability, markdown rate, or mix), and the decision (one action, one accountable owner, one due date). The critical discipline in that fourth field: never end a report with an unexplained red or green KPI. A red number without a stated action creates anxiety without direction; a green number without a stated next step wastes an opportunity to lock in whatever's working.

## Building the One-Page Version

For a single store leader reporting weekly or monthly results (rather than a multi-store or regional review), the one-page version compresses to a small number of core sections: an executive-summary paragraph following the context-insight-action structure above; the core numbers from this course's Module 6 dashboard (sales vs. plan, conversion, ATV, UPT, GMROI, or whichever subset is most relevant this period) each shown with its comparison point; the specific driver or drivers identified using Module 7's diagnostic decision tree; and a short action list, each item with a named owner and a due date. This is deliberately not a dashboard dump — every element on the page should answer a specific question a district manager or owner actually has, not simply display everything the store's systems are capable of producing.

## A Script for the Verbal Version

Beyond the written page, a short, rehearsed verbal script makes the same structure work in a live conversation or a phone update: "Overall, the business is performing [above/at/below] plan. Sales are [up/down] [X percent], driven by [the specific driver identified through diagnosis]. The biggest opportunity right now is [X], and the biggest risk is [Y]. Our focus moving forward is [specific action]." This script forces the same context-insight-action discipline into a conversational format, and having it rehearsed means a manager doesn't scramble for words when a district manager calls unexpectedly asking how the week went.

## Setting Individual Targets From the Store Target

The other half of this course's final terminal outcome — setting individual targets from store targets — uses a specific, well-documented cascading-goals logic: start with the store's own top-level target (sales vs. plan, for instance), then break that target down into what each function or role needs to contribute, ensuring each individual's target is specific, measurable, and clearly tied to the store-level goal it supports, rather than an arbitrary number handed down without explanation. A sales associate's individual target isn't simply "the store target divided by headcount" — it should account for that associate's actual scheduled hours, their specific role (a bridal specialist's target looks different from a general sales associate's), and should be built with the associate's own input where practical, since goals employees help shape generate more genuine ownership than goals purely imposed from above.

## Keeping the Cascade Honest

A specific discipline that keeps cascaded targets fair rather than punitive: the sum of individual targets should reconcile back to the store-level target in a way every associate can see and verify, and targets should be revisited on a regular review cadence rather than set once and forgotten. This matters directly for morale and trust — an associate who suspects their individual number was set arbitrarily, without a visible connection to the store's actual goal, has much less reason to commit to hitting it than an associate who can trace their specific target back to the store number and see exactly how their contribution fits into the larger picture.

## Putting the Vocabulary to Work

The complete reporting cycle this course has built, module by module: Module 6's dashboard produces the numbers; Module 7's decision tree diagnoses what's driving them; and this module's context-insight-action structure turns that diagnosis into a report a leader actually trusts and acts on, while the cascading-goals logic turns the same store-level numbers into individual targets the team can see themselves in. A store leader who runs this full cycle consistently is doing exactly what this course's terminal outcomes describe: defining and calculating the vocabulary, building the dashboard, diagnosing the miss, setting the individual targets, and presenting the results upward.

## A Worked Scenario: The Report That Actually Got a Budget Approved

A store manager's monthly report to the district office states plainly: sales were 6 percent below plan, driven specifically by a conversion drop traced (using Module 7's decision tree) to inconsistent Saturday-afternoon staffing coverage during the store's highest-traffic window. The report's action line requests a modest increase in part-time scheduled hours specifically for that window, with a named associate as the accountable owner for the revised schedule and a four-week review date to confirm conversion recovers. Because the report names a specific, diagnosed driver rather than a vague explanation, and asks for a specific, bounded resource with a review date attached, the district manager approves the request in the same conversation — a report built on guesswork or a vague "we need more staff" ask would likely have been deferred pending further review.

## Key Takeaways

- Effective upward reporting follows a specific three-part flow: context (what happened), insight (why it happened, using Module 7's diagnostic discipline), and action (what happens next, with a named owner and due date) — never ending on an unexplained red or green KPI.
- A genuinely useful executive summary contains four required fields: the current-period result, the comparison to plan and prior year, the specific driver(s) explaining the movement, and a stated decision with an accountable owner and due date.
- A one-page store report is deliberately not a dashboard dump: every element should answer a specific question a district manager or owner actually has, built from the same dashboard (Module 6) and diagnosis (Module 7) this course has already established.
- A rehearsed four-sentence verbal script ("Overall, the business is performing... Sales are... driven by... Our focus moving forward is...") makes the same context-insight-action discipline work in a live conversation, not just a written page.
- Individual targets should cascade transparently from the store-level target, accounting for each associate's actual role and hours, with the sum reconciling visibly back to the store goal — a target an associate can trace back to the store number generates far more genuine ownership than one handed down without explanation.
