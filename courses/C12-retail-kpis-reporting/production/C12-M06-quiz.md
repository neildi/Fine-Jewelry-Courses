# C12-M06 Quiz: Building the Weekly Dashboard

**Instructions:** Answer all questions.

---

**1. What is the core design principle regarding the number of headline KPIs on a weekly dashboard?**
A) Include every KPI the POS system can display, since more data is always better
B) Limit the dashboard to roughly five to eight headline KPIs, since a dashboard crowded with secondary metrics makes the genuinely important numbers harder to spot
C) A dashboard should contain exactly one number and nothing else
D) The number of KPIs on a dashboard has no effect on its usability

**Correct answer: B**
Explanation: This principle is confirmed across multiple independent dashboard-design sources, which converge on a consistent range even while using slightly different exact numbers.

---

**2. What question does Row One of the four-row dashboard structure answer, and what metrics does it use?**
A) "Is it inventory?" using sell-through and turnover
B) "Was the period good?" using net sales versus plan, transaction count, gross profit margin, GMROI, and sales per square foot
C) "What did our competitors do this week?" using competitor pricing data
D) Row One has no specific question or purpose

**Correct answer: B**
Explanation: This is the outcome-level row a manager checks first; if the answer is a clear yes, no further discussion is needed at this level.

---

**3. What question does Row Two answer, and what metrics does it use?**
A) "Was the period good?" using the same metrics as Row One
B) "Is it demand or basket?" using foot traffic, conversion rate, average transaction value, and units per transaction
C) Row Two focuses exclusively on employee scheduling data
D) Row Two has no relationship to any other row

**Correct answer: B**
Explanation: These driver-level numbers explain why Row One's outcome metrics look the way they do.

---

**4. In the outcome/driver/diagnostic metric-classification framework, how would sales versus plan and conversion rate typically be classified?**
A) Both are diagnostic metrics used only in rare, deep investigations
B) Sales versus plan is typically an outcome metric (reviewed every week by leadership), while conversion rate is typically a driver metric (explaining movement in the outcome metric)
C) Both are exactly the same type of metric with no meaningful distinction
D) Sales versus plan is a diagnostic metric and conversion rate is an outcome metric

**Correct answer: B**
Explanation: Diagnostic-level detail (like category- or associate-level breakdowns) surfaces only when a driver metric signals a problem worth investigating further.

---

**5. Why should a dashboard never display a raw number without a comparison point next to it?**
A) Comparison points are decorative and have no functional purpose
B) A number like an 11% conversion rate means almost nothing on its own; the same number next to last month's or last year's figure immediately tells a manager whether to worry or not
C) Comparison points should only be added once a year, not on a weekly dashboard
D) Raw numbers are always more accurate than numbers shown with comparisons

**Correct answer: B**
Explanation: This extends the trend-based benchmarking principle this course established in Module 2 for conversion rate to every number on the dashboard.

---

**6. What is the specific structural fix recommended to prevent a dashboard from collapsing within its first few months?**
A) Retype all data manually into the dashboard every week to ensure accuracy
B) Export raw data directly from the POS/ERP system rather than retyping it, keep raw-data tabs separate from calculation tabs, and build each KPI formula once referencing the raw tabs
C) Rebuild the entire dashboard from scratch every month
D) Avoid using any formulas and instead enter every calculated number by hand

**Correct answer: B**
Explanation: Manual re-entry becomes tedious enough over time that someone eventually starts skipping weeks, which is why an export-based structure is the fix rather than relying on discipline alone.

---

**7. What does the weekly meeting built around this dashboard typically look like, and what should it produce?**
A) An unstructured, open-ended discussion with no fixed agenda or time limit
B) A fixed roughly 30-minute slot, same day each week, reviewing specific metrics (net sales vs. plan, margin, conversion, ATV, UPT, sales per labor hour), ending with concrete outputs like next week's schedule, a promotional focus, and one coaching target per associate
C) A meeting that only happens once per quarter
D) A meeting focused exclusively on employee complaints, with no data review

**Correct answer: B**
Explanation: This mirrors and extends the fixed-slot weekly-review discipline this course already established in C11's Module 10.

---

**8. What is the recommended staged build sequence for a store leader building a dashboard from scratch?**
A) Build all three rows (outcome, driver, inventory) simultaneously from day one
B) Start with Row One (outcome metrics), get it genuinely reliable, then add Row Two (driver metrics), and add Row Three (inventory metrics) last
C) Start with the most complex diagnostic-level metrics first
D) There is no recommended order; all approaches are equally effective

**Correct answer: B**
Explanation: Building all three rows simultaneously from scratch is a common way these projects stall; a staged approach produces a dashboard that survives past its first month.
