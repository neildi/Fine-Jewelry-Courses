# C2 Module 1 Production Record

## Inputs
Module 1: The First 90 Seconds: Openers That Start Conversations
Persona: P1 The New Associate (secondary P2, P3)
KPI: Conversion rate; average ticket; UPT
Terminal outcome: Open without "Can I help you?" and convert the first 90 seconds into a real conversation

## Working title and alternates
1. The First 90 Seconds: Openers That Start Conversations (selected, matches Prompt Kit Part A module title)
2. Alternate: Past "Can I Help You?": Openers That Actually Work
3. Alternate: The Greeting That Buys You a Conversation

## Scenario hook
A new associate uses "Can I help you find anything?" on a bridal-case browser, gets "just looking," and loses the client in eleven minutes with no further exchange.
