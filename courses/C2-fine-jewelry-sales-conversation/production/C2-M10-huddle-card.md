# Huddle Card: Role-Play Scripts and a Weekly Practice Cadence

**Headline:** Reading a module once isn't the same as being able to use it. Practice is what makes it stick.

**3 key points:**
1. Role-play off the floor, never in front of real customers. The client role should challenge realistically, not sabotage or recite a fixed script.
2. Run short, frequent practice (about 15 minutes) rather than one long session: a quick warm-up, a focused role-play drill, and specific feedback tied to observable behavior.
3. Rotate older scenarios back in every week, not just the newest topic. Spaced review keeps earlier skills (openers, buying signals) from fading while newer ones (closing) are being built.

**Script to practice today:**
Run Scenario 1 from this module: client browses the bridal case and says "just looking." Associate practices avoiding "Can I help you?" and responds to the brush-off with an open-ended follow-up.

**Question to ask the team:**
