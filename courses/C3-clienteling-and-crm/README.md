# C3 Clienteling & CRM

**Track:** Foundations
**Personas:** P1, P2, P3
**8 articles, 6-8 learner hours**
**Research anchor:** Fine-Jewelry-Career-Guide.md (clienteling cadences, CRM platforms, life-milestone outreach); Fine-Jewelry-Retail-Career-and-Skills-Reference.md (clienteling competency, VIC portfolio building)

## Terminal outcomes

The learner can:
- Build an accurate, privacy-respecting client profile from a single conversation and grow it over repeat visits
- Run a structured outreach cadence (post-sale, milestone, and win-back) without sounding automated
- Use CRM/clienteling software (e.g. The Edge, Clientbook) to prioritize daily and weekly outreach rather than relying on memory
- Identify and prioritize Very Important Clients (VICs) without neglecting the rest of the book
- Turn life-event triggers (birthdays, anniversaries, milestones) into genuine, well-timed touches
- Re-engage a lapsed client respectfully, without sounding like a discount blast
- Convert a satisfied client relationship into referrals, systematically rather than by chance

**Assessment:** Observed clienteling-note review; a manager-scored 30/60/90-day outreach plan for five real clients.
**KPI link:** client retention rate, repeat-purchase rate, referral rate, data-capture percentage, average client lifetime value.
