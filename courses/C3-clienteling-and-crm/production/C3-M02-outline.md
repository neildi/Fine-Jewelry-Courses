# C3 Module 2 Production Record

## Inputs
Module 2: The Clienteling Calendar: Cadences That Feel Personal, Not Automated
Persona: P1 The New Associate (secondary P2, P3)
KPI: Repeat-purchase rate; average annual transactions per active client; opt-out/complaint rate
Terminal outcome: Run a structured outreach cadence built from post-sale, date-based, service-based, and win-back triggers, calibrated to feel like attentive service rather than either silence or a marketing blast

## Working title and alternates
1. The Clienteling Calendar: Cadences That Feel Personal, Not Automated (selected, matches C3 course README module title)
2. Alternate: Two Clients, Two Kinds of Silence
3. Alternate: The Six Triggers Worth Running

## Scenario hook
Two clients: one forgotten for 18 months, one who unsubscribed after three unrelated promotional blasts. Neither experienced real clienteling; the calendar in this module fixes both failure modes with the same tool.
