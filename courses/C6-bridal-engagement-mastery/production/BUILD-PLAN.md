# C6 Build Plan

## Persona

## Drafting discipline (restated from the SOP)

- Use only facts in `<evidence>`; no invented statistics, percentages, or prices; phrase unsourced common practice as "many stores… / a typical approach…".
- `[VERIFY]` on any uncertain claim; resolve against a primary source before removing.
- No legal/financial/appraisal advice framed as certain; defer to store policy and local regulation.
- Dialogue form: `Client: … / Associate: …`. No exclamation points, no emoji, no italics for emphasis.
- Length is need-driven (the project's no-cap policy), not padded to a fixed count.
