# C4-M08 Outline: Internal Controls and Building a Security Culture

## Module Metadata
- Course: C4 - Store Security & Loss Prevention
- Module: 8 of 8 (course capstone)
- Persona: P2
- Working title: Internal Controls and Building a Security Culture
- Learning objective: Associates can articulate the "no single point of failure" principle underlying every prior module, apply segregation-of-duties thinking at the organizational level, and understand the JSA weekly crime bulletin and Suspicious Incidents Book as structural (not incidental) habits.
- Terminal outcome tie-in: "Explain segregation-of-duties principles and contribute to a store-wide security culture (crime bulletins, suspicious-incident logging, training log sign-off)."

## Section Map

1. **Why This Module Matters** — States the JCK internal-theft principle ("no one except the owner should have sole authority for any function") as the thread connecting every prior module.
2. **The Core Principle: No One Person, No Single Point of Failure** — Explicit mapping of Modules 1, 2, 3, 5, and 7's specific rules back to this single underlying principle.
3. **Segregation of Duties at the Organizational Level** — Extends counting-specific segregation (Module 7) to cash handling, role rotation, digital key logging, and unscheduled inspections store-wide.
4. **The JSA Weekly Crime Bulletin: A Structural Habit, Not a Suggestion** — Training-log sign-off as both a currency-of-knowledge habit and documented-culture evidence.
5. **The Suspicious Incidents Book, Revisited as a System** — Elevates Module 1/4's logging habit into a reviewed, systematic control rather than an informal notebook.
6. **Bringing the Whole Course Together** — Explicit module-by-module capstone synthesis (Modules 1-2 perimeter/vault, Module 3 selling floor, Module 4 pattern recognition, Modules 5-6 transaction/compliance, Module 7 record accuracy, Module 8 organizational structure).
7. **Metrics Worth Tracking** — Ties the course's five KPI-link metrics back to specific modules, explaining what a metric anomaly actually signals about which module's discipline may be lapsing.
8. **Practice Exercise** — Store-wide gap-mapping exercise across all module controls, prioritized to one gap for manager discussion.
9. **Key Takeaways** — Five-point recap.
