# C4-M03 Huddle Card: Showcase and Selling-Floor Security

## 5-Minute Pre-Shift Discussion

**The one idea to remember:** Showcase security fails in routine moments, not dramatic ones. The protocol only works if you run it every single time, not just when something feels "off."

## The Full Sequence, Every Time
1. Unlock case → remove ONE item only
2. Loupe it before handing it over
3. Lock the case immediately, even if you're standing right there
4. Never leave the customer alone with it — not even for a second
5. Loupe it again when it comes back (anti-switch check)
6. Return to case and re-lock, or complete the sale

## Red Flag, Not Reassurance
A customer flashing $10,000+ in cash isn't a "secure sale" — it can be a distraction-theft tactic. Tighten protocol, don't relax it.

## Two More Habits
- **Distribute** high-value watches and loose diamonds across several cases — don't concentrate your biggest risk in one spot.
- **Wrist key holder, always.** Keys set down "for a second" are how ordinary distraction becomes a real loss.

## Today's Discussion Prompt
Think of your last showcase interaction. Did you loupe before AND after? Was the case ever unlocked while you weren't holding the item?
