# C4-M07 Outline: Perpetual Inventory, Cycle Counts, and Shrink Control

## Module Metadata
- Course: C4 - Store Security & Loss Prevention
- Module: 7 of 8
- Persona: P2
- Working title: Perpetual Inventory, Cycle Counts, and Shrink Control
- Learning objective: Associates can participate correctly in a cycle-count program, apply the five-step discrepancy protocol before concluding a loss, and understand the segregation-of-duties controls that support accurate counting.
- Terminal outcome tie-in: "Participate in a perpetual-inventory and cycle-count program, and follow the correct discrepancy protocol before declaring a loss."

## Section Map

1. **Why This Module Matters** — Extends Module 2's perpetual-system setup into day-to-day operational practice.
2. **Why Annual-Only Counting Is Inadequate** — Trade guidance on weekly/monthly/bimonthly cadence; unannounced/surprise-count rationale.
3. **A Concrete Cycle-Count Model You Can Actually Run** — One-category-per-week model; four-step independent double-count for high-value items above threshold.
4. **The Discrepancy Protocol: What to Do Before You Declare a Loss** — Five-step sequence (recount, repair box, approval-out, recent sales/scan error, last-resort write-off); cluster-investigation principle.
5. **What the POS System Should Actually Support** — Three physical-inventory modes (full/case/partial); reconciliation workflow; stock-status field requirement.
6. **Segregation of Duties in the Counting Process Itself** — Dual signing, rotation, digital key logging, unscheduled inspections.
7. **Reporting Cadence Tied to This Discipline** — Links counting accuracy to Module 2's quarterly/annual insurer reporting cadence.
8. **A Worked Scenario: Applying the Discrepancy Protocol** — Illustrative synthesis walking through the five-step sequence on a specific missing-ring example.
9. **Practice Exercise** — Reflective/forward-looking discrepancy-narration exercise.
10. **Key Takeaways** — Five-point recap.
