# C4-M01 Huddle Card: Opening and Closing: The Two-Person Rule and Alarm Response

## 5-Minute Pre-Shift Discussion

**The one idea to remember:** Never open or close alone. One person enters, gives the all-clear, then everyone else follows. This single rule addresses the single most dangerous routine of the retail day.

## The Sequence
**Opening:** Inspect surroundings → one person enters, locks door behind them, checks interior → all-clear signal → others enter and lock the door immediately → merchandise comes OUT of the safe → THEN doors unlock to customers.

**Closing:** Clear all customers → lock the door → THEN merchandise goes back INTO the safe → showcases locked, keys removed → never reopen for any reason.

## Key Rules
- Premises keys and safe keys: never held by the same person.
- Never cover a loaded case overnight instead of putting it away — a burglar reads a covered case as "something's under there."
- Check window frames and showcases for tampering daily, not weekly.

## Alarm Response
1. Never enter alone — wait for police.
2. Treat every signal (even "communication error") as real.
3. Verify any callback using the alarm company's published number, never the number a caller gives you.

## Today's Discussion Prompt
Walk through this week's opening or closing routine out loud together — where in the sequence would each of us be standing, and who gives the all-clear signal?
