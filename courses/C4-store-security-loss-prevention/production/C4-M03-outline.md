# C4-M03 Outline: Showcase and Selling-Floor Security

## Module Metadata
- Course: C4 - Store Security & Loss Prevention
- Module: 3 of 8
- Persona: P1
- Working title: Showcase and Selling-Floor Security
- Learning objective: Associates can execute the full showcase selling protocol (lock, loupe before/after, one item at a time, never leave customer alone with merchandise), recognize cash-flash as a possible distraction-theft cue, and use a wrist key holder as standard practice.
- Terminal outcome tie-in: "Apply anti-switch and one-item-at-a-time selling-floor protocols when showing high-value merchandise."

## Section Map

1. **Why This Module Matters** — Frames showcase interactions as high-frequency, routine risk, contrasted with the rare/dramatic risk covered in Modules 1-2.
2. **The Core Selling Protocol** — Jewelers Mutual's seven-step sequence in full.
3. **The Anti-Switch Control: Why You Loupe Before AND After** — JSA's rationale; why the sequence specifically catches substitution.
4. **One Item at a Time, and Distributed Storage for High-Value Pieces** — Risk-concentration logic; AGTA/JSA distributed-storage recommendation for watches/loose diamonds.
5. **Cash as a Red Flag, Not a Reassurance** — National Jeweler/JSA quote on $10,000 cash flash as distraction-theft cue; reframing the intuitive read.
6. **Photo ID and Private Showrooms: Escalating Controls for Escalating Value** — Proportionate-control principle.
7. **Wrist Key Holders: A Small Habit With an Outsized Payoff** — Ordinary-distraction failure mode, not a dishonesty issue.
8. **How This Connects to the Rest of the Course** — Links Module 1's "dangerous because predictable" framing to this module's "risky because routine" framing.
9. **A Worked Scenario: Putting the Sequence Together** — Step-by-step tennis-bracelet example.
10. **Practice Exercise** — Self-audit of last five showcase interactions.
11. **Key Takeaways** — Five-point recap.

## Ties to Other Modules
