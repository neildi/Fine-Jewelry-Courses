# C4-M07 Huddle Card: Perpetual Inventory, Cycle Counts, and Shrink Control

## 5-Minute Pre-Shift Discussion

**The one idea to remember:** Never jump straight to "it's stolen." Recount, check repair, check approval-out, check recent sales for a scan error — theft is the LAST conclusion, not the first.

## The Discrepancy Protocol, In Order
1. Recount the location
2. Check the repair log
3. Check approval-out records
4. Check recent sales for a scanning mix-up
5. Only now: document it as a real loss

## Why Counts Should Be Unannounced
If everyone knows exactly when and what gets counted, that predictability can be worked around. Surprise counts on specific categories catch what a scheduled count might miss.

## The Four-Step High-Value Count
For anything above the store's high-value threshold: two people count independently → compare → a third person recounts any differences → only then adjust the system.

## Segregation of Duties, Applied to Counting
- Whoever signs for incoming shipments shouldn't also count that same stock.
- Roles should rotate — it prevents both errors and collusion.
