# C11-M03 Huddle Card: Weekly Counts, Coaching, Client-Book Review

## 5-Minute Pre-Shift Discussion

**The one idea to remember:** A week is long enough to catch a real problem while it's still small. Same slot, same reports, same discipline — every week.

## The Weekly Business Review (Monday Morning, <15 Minutes)
1. Turnover: product vs. gift-card, vs. last year and last 4 weeks
2. Net profit margin
3. Repairs: completed / open-within-deadline / OVERDUE
4. Customer + old-gold purchases — who's worth a call this week?
5. Top and bottom sellers

## Weekly Cycle Count
One category per week — whole store counted by year-end. PLUS random, unscheduled spot-checks (scheduled counts can be "prepared for").

## Before You Ever Call It a Loss
1. Recount
2. Check the repair log / out-on-approval
3. Check recent sales for a scan error
4. ONLY THEN write it off

Don't jump straight to "theft." Most discrepancies aren't.

## The Weekly Team Meeting
Not just announcements — ACCOUNTABILITY. Are thank-you notes actually going out? Contact preferences actually honored? Review repair take-ins and tomorrow's due jobs. Run a training topic.

## Client-Book Review: Spot-Check, Don't Assume
Pull 5 real client records. Check the 2-2-2 cadence (2 days, 2 weeks, 2 months) against what ACTUALLY happened, not what should have.

## Today's Discussion Prompt
Pull one recent inventory discrepancy from memory. Did we run the full sequence before drawing a conclusion?
