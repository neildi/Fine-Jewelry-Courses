# C11-M02 Outline: The Daily Rhythm: Open, Huddle, Floor, Close

## Module Metadata
- Course: C11 - Running the Store
- Module: 2 of 10
- Persona: P1/P7 (First-Time Store Leader, per this project's official course architecture)
- Working title: The Daily Rhythm: Open, Huddle, Floor, Close
- Learning objective: Store leaders can run and verify the two-person opening sequence, lead a structured daily huddle, actively coach and watch for security exceptions during the working day, and run the closing sequence in the correct customers-out-then-merchandise-away order.
- Terminal outcome tie-in: Directly fulfills the C11 terminal outcome (per this project's official course architecture document) that "the manager can run the daily open-huddle-floor-close sequence."

## Section Map

1. **Why This Module Matters** — Frames the daily rhythm as a response to jewelry retail's documented high-severity, high-shrink risk profile, not arbitrary house style.
2. **Why Opening and Closing Get Treated as the Riskiest Routine of the Day** — JSA crime statistics and timing data establishing the risk basis for the sequence.
3. **Opening: The Two-Person Sequence, in Order** — The specific, ordered opening protocol (entry/all-clear, merchandise out, case verification, doors unlock).
4. **The Morning Huddle: A Short, Structured Briefing, Not an Afterthought** — Leader-level huddle ownership vs. associate-level participation; in-the-moment coaching.
5. **Working the Floor: What a Leader Is Actually Watching For** — Daily coaching and security-exception vigilance (distraction theft, suspicious-incident logging).
6. **Closing: Customers Out, Then Merchandise Away** — The specific, ordered closing protocol and leader-level cash/deposit responsibilities.
7. **A Worked Scenario: The Huddle That Almost Got Skipped** — Illustrative synthesis showing a compressed but not-skipped huddle under real time pressure.
8. **Practice Exercise** — Comparing the learner's actual store sequence against this module's documented protocol.
9. **Key Takeaways** — Five-point recap.
