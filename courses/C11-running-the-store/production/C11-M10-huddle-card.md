# C11-M10 Huddle Card: The Manager's Own Weekly Scorecard

## 5-Minute Pre-Shift Discussion

**The one idea to remember:** Fifteen minutes, same day, same five numbers, every week — that's how you catch a drift before it becomes a miss.

## The Five-Number Weekly Review
1. **Turnover** — this week vs. same week last year vs. prior 4 weeks
2. **Net profit margin** — same period
3. **Repair pipeline** — completed / open-within-deadline / overdue
4. **Customer + old-gold purchases** — who's worth a call this week
5. **Top-ten / bottom-ten sellers** — across product, category, seller, date range

## The Three Numbers Leadership Cares About
- **Sales vs. plan** — built on Modules 2-3's daily/weekly rhythm
- **Shrinkage rate** — built on Module 4's verification protocol + Module 7's pipeline visibility
- **Visual-merchandising audit score** — built on Module 5's case-zoning standards

## One Page. Same Slot. Every Week.
Monday morning works well. Same five reports, same order, every time — that removes the friction that kills unstructured reviews.

## Read the Trend, Not Just This Week's Number
One bad week isn't a crisis. Three weeks of climbing shrinkage against flat sales-vs-plan is a signal — trace it back to Module 4 or 7 before it compounds.

## A Gap on the Scorecard = A Signal to Revisit an SOP
Repairs consistently overdue? That's not a "try harder" problem — it's a signal the SOP itself (Module 8) needs revisiting.

## Today's Discussion Prompt
Pick one number on our scorecard that's been drifting for more than two weeks. Which module's SOP does it point back to?
