# C7-M03 Fact-Check: Dating and Attribution

## Verification Status: Loupe/examination standards unanimously confirmed; evidence-weighing and conflict-resolution framework explicitly adapted from a non-jewelry-specific provenance methodology

## Claims Reviewed

**1. 10x triplet loupe as the gemological industry standard for hand-held examination.**
Status: CONFIRMED CONSISTENT AND UNANIMOUS across six independent sources (CaratX, GemTrue, International Gem Society, JYB Selected, AlfaMirage, manuals.plus's loupe guide) — every source agrees on 10x as the standard, with some noting 14x/20x as supplementary tools for specific diagnostic purposes (e.g., resolving laser drill holes or synthetic flux, per JYB Selected).

**2. Loupe technique (1-2 inches from eye, object brought to loupe not loupe to object, low-angle directed lighting, systematic examination sequence through table/crown/pavilion/girdle).**
Status: CONFIRMED CONSISTENT across GemTrue, All Diamond UK, and manuals.plus — all three independently describe matching distances, hand positioning, and the practice of moving the object rather than the loupe. The specific table-crown-pavilion-girdle sequential examination order is sourced from CaratX's gemstone verification guide.

**3. Documentation-throughout practice (photographing marks/joins/stones before any cleaning or repair).**
Status: This is standard, widely-recognized professional appraisal practice; the specific framing used in this module (protecting the associate/store if a client later disputes observations; building an internal reference library) is this module's own synthesis of generally accepted appraisal documentation norms, not a single specific cited source.

**4. Evidence-weighing framework (precise testable claims; independent vs. derivative/repeated evidence; qualified date ranges over invented precision; distinguishing whole object from components).**
Status: IMPORTANT SOURCING NOTE — this framework is adapted from Collectaneum's "Conflicting Evidence" guide, which is a general provenance/authentication methodology written for collectibles broadly (art, antiques, historical objects), NOT a jewelry-trade-specific source. The underlying logic (testable propositions, weighing independent sources, qualified language, documenting before altering evidence) is sound and directly transferable, and this module explicitly applies it to the jewelry-specific attribution context established in Module 2, but it should be understood as a reasoned adaptation rather than jewelry-trade-specific primary sourcing.

**5. Married jewelry definition and its legitimate, non-fraudulent history.**
Status: Sourced directly from Lang Antiques' "Married Jewelry" glossary entry, part of Lang Antiques' Antique Jewelry University — a well-established, jewelry-trade-specific reference source already cited in this course's research anchor documents (Free-Learning-Resources file, Section 5). This is a credible, on-point, single-source definition; the general concept (heirloom re-setting as a common, legitimate practice) is consistent with widely-known trade norms.

**6. Conflicting-evidence discipline (testing whether a conflict is real, listing plausible explanations, documenting reasoning, recognizing when a conclusion should remain open).**
Status: Same sourcing note as item 4 above — adapted from Collectaneum's general provenance-conflict methodology, applied here to a jewelry-specific married-piece scenario. This is a reasoned, clearly-labeled adaptation, not a direct jewelry-trade citation.

**7. Referral-to-outside-expertise guidance.**
Status: This is a general professional-judgment principle consistent with the credential requirements described in this course's own research anchor documents (e.g., the Estate Jewelry Specialist role profile's GIA Graduate Gemologist requirement, and Sotheby's/Heritage Auctions' formal appraisal credentialing expectations), rather than a single specific external citation.

**8. Worked scenario and practice exercise.**
Status: ORIGINAL illustrative synthesis created for this module, not drawn from any external source.
