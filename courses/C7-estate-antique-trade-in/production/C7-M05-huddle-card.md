# C7-M05 Huddle Card: Appraisals for Estate and Trade-In

## 5-Minute Pre-Shift Discussion

**The one idea to remember:** ALWAYS ask "what is this appraisal actually for?" before producing anything. The wrong value type isn't a technicality — it can cost a client real money in taxes or a settlement.

## The Three Values, Ranked
**Retail Replacement > Fair Market Value > Liquidation Value**
- RRV: cost to replace new at retail (includes markup) — for INSURANCE
- FMV: willing buyer + willing seller, no pressure, ~30-60% of RRV — for ESTATE/PROBATE/DONATION/often DIVORCE
- Liquidation: forced/urgent sale, ~10-30% of RRV — for BANKRUPTCY/court-ordered rapid sale

## The Purpose Match (Memorize This Table)
| Client says... | They need... |
|---|---|
| "For my insurance" | Retail Replacement Value |
| "I'm the executor / settling an estate" | Fair Market Value |
| "For a tax-deductible donation" | Fair Market Value |
| "Getting divorced" | FMV or Marketable Cash Value (ask which — varies by case) |
| "Need cash fast / bankruptcy" | Liquidation Value |

## Why This Matters
Wrong value type on an estate filing = inflated tax bill. Wrong value type in a divorce = an unfair settlement. This isn't paperwork — it's real money for someone going through a hard time.

## Today's Discussion Prompt
Practice asking "what will this appraisal actually be used for?" as your FIRST question, before discussing anything about the piece itself.
