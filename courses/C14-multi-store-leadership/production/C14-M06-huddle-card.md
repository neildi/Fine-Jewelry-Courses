# C14-M06 Huddle Card

**Headline:** A cadence beats a phone call every time.

**Key points:**
1. District communication has three layers — daily (store-owned), weekly (district-owned, fixed format), and monthly (jointly-owned, strategic) — and mixing them up is why the same questions keep repeating.
2. The weekly district check-in should use the same short question set with every store, every time, so it takes minutes, not hours.
3. A written bulletin nobody has to acknowledge is a bulletin nobody has to read — build in a confirmation step.

**Script to practice today:** "Same five questions as always: sales versus plan, anything overdue, any flags, anything you need from me, anything I need to know."

**Question to ask the team:** Which of our current store touchpoints are actually unstructured catch-up calls in disguise, and which store hasn't flagged a problem in the longest time?
