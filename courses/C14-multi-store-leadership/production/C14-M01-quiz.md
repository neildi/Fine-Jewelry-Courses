# C14-M01 Quiz: From Running a Store to Running Managers

**Instructions:** Answer all questions.

---

**1. What is the core mindset shift this module describes when moving from running a store to running managers?**
A) The job stays exactly the same, just with more people to manage directly
B) The job shifts from personally solving problems to developing managers who can solve problems themselves before the district leader ever hears about them
C) Multi-unit leaders should personally solve every problem across every store to maintain quality
D) There is no meaningful difference between single-store and multi-unit leadership

**Correct answer: B**
Explanation: This is described as the "DM Multiplier Effect" — the difference between a struggling and a great multi-unit leader.

---

**2. What is a district manager's primary job, according to this module?**
A) To personally execute every store's daily operations
B) To develop store managers who can run their locations without the district manager present
C) To replace the need for store managers entirely
D) To visit every store every single day without exception

**Correct answer: B**
Explanation: This is sourced directly from a detailed district manager job description source.

---

**3. Why can the skills that made someone an excellent store manager actually work against them in a multi-unit role?**
A) Store manager skills are always identical to district manager skills with no adjustment needed
B) A store manager operates within an operations manual providing daily guidance, while a district manager has no equivalent script and must self-direct across multiple, differently-challenged locations; trying to run a district like one big store fails specifically because it requires a different mindset, not just more repetition
C) Store managers never develop any transferable skills at all
D) District managers should always ignore everything they learned as a store manager

**Correct answer: B**
Explanation: A leader promoted without specific training in this different skill often simply doesn't know how to identify and prioritize issues across multiple locations.

---

**4. What are the four specific capabilities this module identifies as distinguishing successful multi-unit managers?**
A) Speed, volume, aggression, and personal charisma
B) Developing others' strengths, letting go of control, looking at the big picture every day, and avoiding getting caught up in doing the store's job
C) Only technical product knowledge matters at the multi-unit level
D) There are no specific capabilities that distinguish multi-unit leadership from single-store leadership

**Correct answer: B**
Explanation: These four capabilities are named directly across multi-unit-retail-leadership research.

---

**5. What is the "leading from a distance" challenge this module describes?**
A) Multi-unit leaders never need to build relationships with the people they oversee
B) Building a strong relationship with someone seen daily is fundamentally different from guiding and motivating someone seen only on periodic store visits, requiring deliberate communication discipline
C) Distance has no effect on relationship-building or leadership effectiveness
D) Multi-unit leaders should avoid all contact with store managers between visits

**Correct answer: B**
Explanation: This structural challenge doesn't exist at the single-store level, where daily presence makes relationship-building easier.

---

**6. Why does this module emphasize following up on delegated tasks as "where the real leadership work happens"?**
A) Following up has no practical value once a task has been delegated
B) Since a district leader must delegate rather than do tasks personally, a district leader who never follows up teaches store managers that delegated responsibilities are optional; consistent follow-up (without micromanaging) builds the accountability that makes the structure function
C) Following up should always involve redoing the delegated work personally
D) Delegation should never be followed up on at any level of leadership

**Correct answer: B**
Explanation: This is a specific, practical discipline named repeatedly across district-management research.

---

**7. Why does a district manager need a deliberate system for consistency across stores, unlike a single-store manager?**
A) Consistency is automatically guaranteed across multiple locations with no additional system needed
B) A single-store manager only needs to maintain consistency within one location, following an operations manual, while a district manager overseeing multiple stores with different specific challenges needs a system to observe and reinforce consistency across all of them
C) Consistency across stores is impossible to achieve and should not be attempted
D) Only corporate headquarters, never a district manager, is responsible for cross-store consistency

**Correct answer: B**
Explanation: This is a structural challenge unique to the multi-unit role that a single-store manager never needs to solve.

---

**8. In the worked scenario, why did the same merchandising problem keep recurring across stores despite the district manager personally fixing it during visits?**
A) The problem was actually unfixable regardless of who addressed it
B) By personally fixing the display each time, the district manager taught store managers that visible problems would be solved by someone else showing up, rather than building the store managers' own capability to catch and fix such issues independently
C) The store managers were incapable of ever learning to fix the problem
D) The district manager never actually visited the stores in question

**Correct answer: B**
Explanation: The problem stopped recurring only once the district manager shifted to coaching the store manager through the fix themselves, followed by a check-in at the next visit.
