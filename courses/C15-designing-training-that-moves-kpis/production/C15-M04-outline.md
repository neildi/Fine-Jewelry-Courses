# C15-M04 Outline / Media Record

**Working title:** Train the Trainer for Store Managers
**Alternates:** "The Manager as Multiplier"; "Teaching Managers How to Deliver, Not Just What to Deliver"

**Scenario hook:** A trainer builds a strong scenario bank and huddle sequence, but delivery quality varies wildly across stores because store managers were never specifically taught how to run the practice, only given the content.

**Section outline:**
1. Why This Matters — reader connects named train-the-trainer resources (NDC, NHPA) to the distinct skill of delivery vs. content knowledge.
2. What a Manager Needs Beyond Knowing the Content — reader can identify the delivery-specific skills (introducing, observing, feedback, time management) separate from content mastery.
3. Running a Train-the-Trainer Session — reader can structure a demonstrate-then-practice-then-feedback session for managers.
4. The Manager as Multiplier, Not Bottleneck — reader connects train-the-trainer to scaling Module 2/3's designs across multiple stores.
5. Objections, Mistakes and Edge Cases — reader avoids the "good salesperson = good trainer" assumption and one-time-event trap.

**Facts used, with placement:**
- NDC Diamond Learning Center includes named "Train the Trainer facilitator guides" for store managers coaching bridal diamond storytelling → Section 1
- NHPA free training library separately names "Train the Trainer" and "Trainer's Toolbox" as distinct resources → Section 1
- Cross-reference to this project's own C13 Module 5 ("Floor Coaching: Observe, Debrief, Practice") as existing coaching-skill foundation → Section 2
- Cross-reference to C14 Module 2 (store visits) as a model for spot-checking a skill after initial training → Section 5 (objections)

**Gaps not covered in evidence:** No specific named train-the-trainer session structure or agenda template was found verbatim in the supplied research beyond the existence of the NDC/NHPA resources; the demonstrate-practice-feedback session structure is original synthesis modeling standard train-the-trainer practice, not a verbatim sourced framework — flagged for reviewer awareness.
