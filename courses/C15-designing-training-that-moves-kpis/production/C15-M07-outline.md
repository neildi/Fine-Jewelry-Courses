# C15-M07 Outline / Media Record

**Working title:** Curriculum Roadmaps by Career Stage
**Alternates:** "Using This Catalog's Own Persona Roadmaps"; "Sequencing, Not Writing, New Curriculum"

**Scenario hook:** A trainer keeps building one-off learning sequences from scratch for each new hire and promoted manager, unaware this catalog already has a complete persona-to-course roadmap system built and ready to use.

**Section outline:**
1. Why This Matters — reader connects the existing Part A4 persona-to-course paths and NHPA's Path to Success to the general principle of stage-based sequencing.
2. The Four Career Stages Already Defined — reader can map the four-stage career progression to existing course entry points.
3. Building a Roadmap From Existing Modules, Not New Content — reader can sequence existing modules into a roadmap rather than writing new content.
4. Keeping the Roadmap Current as People Advance — reader connects roadmap maintenance to C14's succession-planning module.
5. Objections, Mistakes and Edge Cases — reader avoids building a parallel framework and treating the roadmap as rigid.

**Facts used, with placement:**
- Prompt Kit Part A4: persona-to-course learning paths for all nine personas (P1-P9) → Sections 1, 2, 3
- NHPA Path to Success: recommended learning path by career stage, foundational to leadership, described as a curriculum roadmap skeleton → Section 1
- Career-and-Skills-Reference Section 5: four-stage career progression map (Stage 1 Entry through Stage 4) with resource pairing → Section 2
- Quick-Start Curriculum Suggestion (30-day new associate path, longer district-leader path, all-free resources) → Section 3
- Cross-reference to C14 Module 7 (Talent Pipeline and Succession) → Section 4

**Gaps not covered in evidence:** No new external facts were required beyond this project's own internal architecture and the NHPA resource; the roadmap table and stage-transition checklist are original synthesis organizing existing catalog content, not new sourced claims — flagged for reviewer awareness as an internal-consistency exercise rather than external research.
