# C15 Designing Jewelry Sales Training That Moves KPIs

**Track:** Trainer
**Personas:** P9 (Sales Trainer / L&D Lead), P8 (Multi-Store Leader), per this project's official Course Architecture & Article-Generation Prompt Kit
**8 articles, 8-10 learner hours**
**Research anchor:** R13 of this project's own Fine-Jewelry-Retail-Career-and-Skills-Reference.md; named director-of-sales-training and head-of-training job descriptions (Watches of Switzerland, Moncler, Montblanc); NHPA free training resources (Path to Success, Train the Trainer, Trainers Toolbox); ATD (Association for Talent Development) webinars and Workshop Series; HubSpot Academy Sales Management Training Certification; this project's own C2 (Sales Conversation), C12 (Retail KPIs), and C13 (Hiring, Coaching & Performance Management) courses, which this course draws on as source material for training design

## Terminal outcomes

The trainer can:
- Write behavioral learning outcomes before designing content
- Design a training module with practice built in, not just information delivery
- Run train-the-trainer sessions for store managers
- Build role-play libraries and scenario banks
- Measure training with pre/post KPI comparison
- Maintain a curriculum roadmap by career stage

**Assessment:** A complete module design with a measurement plan, per this project's official course architecture.
**KPI link:** new-hire ramp time, post-training KPI lift, per this project's official course architecture.
**Resource pairing:** NHPA Path to Success and Trainer's Toolbox, ATD Workshop Series and webinars, HubSpot Sales Management Training Certification, per this project's official course architecture.
