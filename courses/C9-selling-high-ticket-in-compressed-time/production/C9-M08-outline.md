# C9-M08 Outline: Capstone: Running a Full Compressed-Time Selling Event

## Module Metadata
- Course: C9 - Selling High-Ticket in Compressed Time
- Module: 8 of 8 (Capstone)
- Persona: P3
- Working title: Capstone: Running a Full Compressed-Time Selling Event
- Learning objective: Associates can execute a full compressed-time selling event simulation that integrates genuine urgency (M1), compressed discovery (M2), fast trust-building (M3), pressure-free closing (M4), event logistics (M5), onboard-retail-specific practices where relevant (M6), and honest fast follow-up for unclosed opportunities (M7), under realistic overlapping, simultaneous demands.
- Terminal outcome tie-in: "Apply this course's full framework in a capstone simulation of a complete compressed-time selling event."

## Section Map

1. **Why This Module Matters** — Frames the capstone as testing whether all seven prior modules' skills hold up together under simultaneous pressure, not any one skill in isolation.
2. **What This Capstone Actually Assesses** — A module-by-module checklist (M1 through M7) translating each prior module's core standard into a specific, observable capstone assessment criterion.
3. **The Simulation Structure** — Three concurrent client scenarios (closes on the spot; needs to think it over; logistical complication) with realistic overlapping timing.
4. **A Worked Scenario: A Ninety-Minute Simulated Trunk Show Window** — Illustrative synthesis walking through a full capstone simulation touching every module's standard.
5. **Practice Exercise (This Is the Capstone Assessment)** — The formal, manager-scored simulation exercise.
6. **Key Takeaways** — Five-point recap.

## Ties to Other Modules
- This module IS the direct fulfillment of the C9 terminal outcome "Apply this course's full framework in a capstone simulation of a complete compressed-time selling event," and integrates all seven prior C9 modules directly rather than introducing new external content.
- Each of the seven module-specific assessment criteria in Section 2 traces directly and explicitly back to that module's own previously-established and fact-checked core claims (see C9-M01 through C9-M07 factchecks), rather than restating them as new claims requiring independent verification here.

## Production Notes
- This capstone module is, by design and by the course's own stated production standard (see the C8 capstone precedent, C8-M08, and the project's six-step SOP describing capstones as "the assessment itself"), primarily an original integrative synthesis rather than a module built on new external research. Every substantive factual claim referenced in this module (genuine urgency, discovery layering, warmth-before-competence, trial-close/silence discipline, event security/staffing benchmarks, onboard-retail ethical practice, and follow-up cadence) was independently sourced and fact-checked in its originating module (C9-M01 through C9-M07 respectively) and is not re-verified as a new claim here; this module's fact-check should be read as confirming correct integration and cross-referencing of those seven already-verified standards, not as introducing new sourced content.
- The three-scenario simulation structure (closes on the spot; needs to think it over; logistical complication) and the worked scenario are ORIGINAL, designed specifically to require simultaneous application of all seven prior modules' skills under realistic overlapping conditions, mirroring the same design logic used in this project's C8-M08 capstone (a mixed, simultaneous job-pipeline simulation) but adapted to this course's event-based, real-time sales-conversation context.
- The practice exercise is this module's formal capstone assessment, per the course's stated assessment plan ("a capstone event-simulation exercise," per the C9 README's Assessment line), and should be treated as the primary evaluative instrument for this course, not a supplementary exercise.

## Estimated Time to Complete

## Assessment Alignment
- This module's practice exercise IS the course's stated capstone assessment, per the C9 README ("a capstone event-simulation exercise"), and should be scored by a manager or trainer against the seven module-specific criteria listed in Section 2, with written feedback identifying which modules' skills held up well and which need further practice.
- No standalone quiz is included for this module, since the live, manager-scored simulation exercise itself is the assessment instrument, consistent with the project's standard capstone treatment (per the six-step SOP: "a one-page huddle card and a 10-question quiz per article, omitted only for modules that are themselves an assessment, e.g. capstones"). A huddle card is still provided to support pre-simulation preparation.
- Huddle card should focus on the seven-point module checklist as a quick pre-simulation and pre-shift reference, since it distills every prior module's standard into a single observable list.
